# Verificación de ECU-TRANSPORT

Escenarios de aceptación, sin soluciones:
1. Compilar los seis archivos sin alterar clases hijas.
2. Agregar seis vehículos de tres tipos.
3. Obtener costos mediante polimorfismo.
4. Buscar placa existente: encuentra el vehículo.
5. Buscar placa inexistente: retorna `null`.
6. Hallar vehículo de mayor costo.
7. Flota vacía: mayor costo `null` y total `0`.
8. Total igual a suma de costos individuales.
9. Mostrar información de todos los vehículos.

Tras crear los archivos faltantes, en `src/`: `javac *.java`, luego `java Main`.

**Estos son casos propuestos, no pruebas ejecutadas.**

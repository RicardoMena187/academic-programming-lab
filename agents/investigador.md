# A3 — Investigador de herramientas y skills

**Objetivo:** seleccionar skills pertinentes sin exponer al estudiante a ejecución insegura.

1. Listar capacidades requeridas.
2. Priorizar skills locales `skills/*/SKILL.md`.
3. Si existe buscador compatible, usar `npx skills find "<tema>"`.
4. Examinar procedencia, instrucciones, dependencias, permisos y compatibilidad.
5. Recomendar, no instalar sin permiso.
6. Si faltan capacidades, describir una skill propia con entrada, pasos, salidas y verificaciones.
7. Diferenciar "encontrada", "revisada", "instalada", "ejecutada" y "no disponible".

**Salida:** matriz de decisión y trazabilidad de skills.

# Descubrimiento de skills
1. Buscar primero `skills/` locales.
2. Si hay herramientas compatibles, consultar `npx skills find "java"`, `"testing"`, `"debugging"`, `"teaching"`.
3. Registrar origen, licencia, dependencias, permisos y compatibilidad.
4. Inspeccionar el contenido antes de recomendar instalaciones.
5. Seleccionar capacidades por valor pedagógico, no popularidad.
6. Pedir autorización antes de instalar o ejecutar recursos externos.
**Salida:** tabla encontrada/revisada/recomendada/instalada/ejecutada.
**Nota:** esta skill local describe un protocolo; no incluye ni instala el buscador externo.

# Implementación pedagógica
1. Revisar diseño aprobado y lenguaje.
2. Ordenar archivos según dependencias.
3. Para cada archivo, explicar su propósito y firmas.
4. Implementar lógica mínima, sin patrones/bibliotecas innecesarios.
5. Añadir Main con objetos concretos y llamadas demostrables.
6. Preparar comandos de compilación y pruebas.
7. Separar claramente código, salida esperada y salida observada.
**Salida:** estructura del proyecto, código completo por archivo, Main y guía de ejecución.

# Diagnóstico de conocimientos
## Entrada
Ejercicio, lenguaje, nivel declarado, contenidos vistos.
## Procedimiento
1. Extraer conceptos imprescindibles.
2. Preguntar como máximo 3 cosas inicialmente, una por intervención.
3. Permitir: domino / repasar / no estudiado / alternativa.
4. Registrar nivel y restricciones.
5. Preparar ruta con microlecciones si hace falta.
## Salida
Tabla de concepto, estado y siguiente acción; diagnóstico provisional sin atribuir certificación.
## Comprobación
No repetir preguntas respondidas. No convertir una conjetura en conocimiento confirmado.

# Depuración guiada
1. Solicitar error exacto o reproducirlo si hay entorno.
2. Describir síntoma, hipótesis y causa verificable.
3. Indicar archivo y ubicación afectada.
4. Mostrar la corrección más pequeña.
5. Volver a ejecutar o dejar estado NO EJECUTADO.
6. Preguntar qué provocó el fallo y ofrecer prueba de regresión.
**Salida:** diagnóstico, parche sugerido, prueba y lección breve.

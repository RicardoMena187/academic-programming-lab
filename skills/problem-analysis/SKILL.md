# Análisis de problemas
1. Leer fuente completa. Señalar explícitos, supuestos y ambigüedades.
2. Identificar archivos inmodificables y restricciones.
3. Extraer entradas, procesos, salidas, condiciones límite.
4. Escribir criterios de aceptación observables.
5. Consultar solo decisiones que alteren la solución.
**Salida:** tabla de requisitos y plan de subtareas.
**Nunca:** inventar contenido de un PDF o archivo inaccesible.

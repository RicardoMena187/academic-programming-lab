# Diseño de evaluación
1. Definir competencia, dificultad, tiempo y tecnología.
2. Redactar enunciado inequívoco con restricciones.
3. Separar archivos dados y archivos a desarrollar.
4. Preparar rúbrica con puntuaciones que sumen exactamente el total.
5. Comprobar que el enunciado sea resoluble sin dependencias no indicadas.
6. Preparar casos de prueba, incluidos límites.
7. Mantener cualquier solucionario fuera del repositorio público.
**Salida:** enunciado, rúbrica, pruebas y lista de resultados observables.
